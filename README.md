# FocusLock

تطبيق Android عربي لإدارة التركيز وحجب التطبيقات التي تختارها.

## البناء
افتح المشروع في Android Studio ثم نفّذ `gradle assembleDebug`.

## التفعيل
1. اختر التطبيقات التي تريد إيقافها مؤقتًا.
2. اضغط «تفعيل الحجب».
3. فعّل خدمة FocusLock يدويًا من إعدادات إمكانية الوصول.
4. ارجع للتطبيق واضغط «إيقاف الحجب» عند الحاجة.

## الخصوصية والتحكم
- الخدمة تستخدم اسم حزمة التطبيق الظاهر فقط ولا تقرأ محتوى الشاشة.
- لا يوجد قفل دائم أو حماية تمنع إزالة التطبيق أو تعطيل الخدمة.
- شاشة الحجب توفر إيقافًا مؤقتًا لمدة خمس دقائق.
- لا يجمع التطبيق بيانات ولا يرسلها إلى خادم.
